# COCO Staking — Frontend

This folder contains a minimal Next.js + TypeScript frontend scaffold for interacting with the COCO staking program.

Quickstart:

1. cd web
2. npm install
3. npm run dev
4. Open http://localhost:3000 and connect a wallet (Phantom recommended)
